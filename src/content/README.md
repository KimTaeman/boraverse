# Content registry

`freebies.ts` lists the eight planned families and their existing destinations. Each existing `01` record is approved for public website preview with placeholders: English messages in D014 and titles/module destinations in D015 (2026-11-16). Their `approved: true` flag permits the web reveal only; it is not print or final-artwork approval. Exact wording is in `docs/08-CONTENT-AND-LORE.md`. `examples/freebies.sample.json` contains planning examples only and is not a production route manifest.

New variants need explicit owner review of IDs, copy, destinations and the intended presentation before public reveal. Unknown and unapproved variants always show a friendly fallback. Final artwork/source rights, canonical printed domain, physical samples and production details remain separate gates. Do not print a QR until these are approved and its final HTTPS route and physical sample have been tested.
